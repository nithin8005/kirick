# KIRIK Website

Marketing site built from the **Kirik Website_DEV** content brief (Excel reference).

## Pages

- **Home** — Hero, stickers, product details, showcase/storyboard, offers, dietary specs, social banner, flavor combos, FAQ preview
- **Products** — Green Chutney, Ginger Jaggery, Kara Podi
- **About** / **Our Story** / **FAQ** / **Terms**

Brainstorm sheet content is excluded per brief.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Replace placeholders

Swap `ImagePlaceholder` components with real assets under `public/images/` when ready.
